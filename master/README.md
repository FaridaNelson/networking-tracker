# Networking Tracker – Master Datasets

The `master/` directory contains the canonical networking datasets used for reporting, evidence generation, and summary statistics.

The files in this directory are **derived datasets**. They should not be edited manually. Each file is generated by a corresponding ETL script in the `src/` directory.

---

## Current Ledgers

### pending_connections_ledger.csv

Canonical ledger of LinkedIn pending connection invitations.

Generated by:

```
src/build_pending_connections_ledger.py
```

Primary key:

```

(PEND-0001, PEND-0002, ...)
```

- linkedin_pending_with_prentus_evidence.csv

## ETL Workflow

```
LinkedIn Exports
        │
        ▼
Processed CSVs
        │
        ▼
Evidence Builders
        │
        ▼
Canonical Ledgers (master/)
        │
        ▼
Weekly / Monthly Summaries
```

---

## Design Principles

- Raw exports are never modified.
- Processed datasets preserve the original records.
- Ledgers are canonical reporting datasets.
- Every ledger uses deterministic record IDs.
- Summary reports are always generated from the ledgers, never directly from raw exports.
